This ensuite needed to feel quiet and bright, so the owners chose one marble-look porcelain and asked us to use it throughout. Large panels cost more to handle, and they leave little room for error, so we flattened the walls before setting anything.

We sorted the panels before installation so the veining flows naturally across the shower wall, then centred the floor layout on the vanity and door. A small herringbone accent behind the vanity uses the same tile colour, cut into narrow strips, to add a little texture without a second material.
